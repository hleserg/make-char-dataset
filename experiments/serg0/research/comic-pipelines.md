# Пайплайны создания комикса с ИИ — ресёрч (2025–2026)

> Deep-research для HLE-923. Контекст: у нас уже ЕСТЬ консистентная char-LoRA персонажа
> (реальный человек в рисованном комикс/акварель-стиле) + отдельная style-LoRA (`cmcstyle`),
> хотим делать многокадровые страницы комикса. 22 источника → 104 утверждения →
> 25 проверены состязательно (20 подтверждено, 5 убито). Источники в конце.

---

## TL;DR (главный вывод)

Консенсус 2025–2026: **процесс ведёт человек, ИИ — ассистент**. Человек владеет сюжетом,
раскадровкой/вёрсткой, леттерингом, эмоциональным нюансом и контролем консистентности; ИИ
делегируют рендер, фоны, цвет, вариации, апскейл/чистку — **с ручной правкой каждого кадра
перед публикацией**.

Самая сложная и **до сих пор не решённая** проблема — **консистентность персонажа между
кадрами** (лучшие модели story-visualization дают всего ~0.54 self-consistency). Решается не
одним приёмом, а **стеком защит**: char-LoRA (якорь личности) + style-LoRA + IP-Adapter/FaceID
(лицо) + ControlNet (поза/композиция) + фикс-сид + character sheet + инпейнт по кадрам.

**Хорошая новость для нас:** у нас уже есть char-LoRA — это и есть самый надёжный якорь
личности. Все споры «LoRA vs IP-Adapter» для нас неактуальны: LoRA = база, остальное —
дополнительные слои поверх для отдельных кадров.

## 1. Разделение труда — чеклист

**DO-BY-HAND (только руками, не делегировать):**
- Сюжет / сценарий / диалоги.
- Раскадровка и вёрстка страницы (панели, gutters, порядок чтения).
- Леттеринг, спич-баблы, SFX (диффузия рисует текст плохо; нужна редактируемая типографика,
  точное размещение, контроль reading-flow).
- Тонкий эмоциональный нюанс (напр. «злится, но глаза грустные» — ИИ это не ловит).
- Финальная правка и QC консистентности перед публикацией.

**CONTROL / REVIEW (ИИ делает, человек жёстко контролит и ревьюит каждый кадр):**
- Поза / композиция / ракурс камеры через ControlNet (OpenPose / depth / lineart / canny).
- Инпейнт по кадрам для фикса дрейфа (~15% генераций дают видимый дрейф).
- Выбор сида, подбор весов LoRA/IP-Adapter.
- Отбор лучших вариантов из пачки.

**DELEGATE-TO-AI (отдать ИИ, ревью по результату):**
- Рендер кадров, фоны, цвет/колоризация, вариации, апскейл и чистка.
- Брейншторм, черновые раскадровки, референсы.

> 57% издателей используют ИИ для фонов/колоризации, оставляя креативное руководство людям.

## 2. Консистентность персонажа — стек защит (самое важное)

Это «несущая» проблема. Практики комбинируют (по убыванию надёжности для нашего случая):

1. **char-LoRA — золотой стандарт** для длинных серий («frame-perfect consistency»). У нас есть.
2. **Стек LoRA**: char + style + (опц.) одежда в одном графе ComfyUI (Checkpoint → LoRA → LoRA →
   KSampler). ⚠️ LoRA могут «драться» → пересвет/потеря личности; **2–3 LoRA — предел
   предсказуемости**, против style-bleed помогает regional prompting. (Нам надо протестить
   связку char-LoRA + `cmcstyle` — источников именно по этой паре нет, проверим эмпирически.)
3. **IP-Adapter / FaceID — поверх LoRA**, для подтяжки лица в отдельных кадрах.
   - `ip-adapter-plus-face` = дообучен на кропе лица, держит лицо ближе.
   - **Вес — ключевая ручка**: IP-Adapter scale ~**0.65** (ниже ~0.7), иначе копирует и позу
     с рефа; FaceID weight ~**0.7–0.8** (1.0 = «пережжённое»/деревянное, 0.5 = не похоже).
   - ⚠️ FaceID/InsightFace деградирует на профиле/три-четверти (эмбеддинги с фронтальных лиц).
   - В 2026 PuLID / InstantID часто называют сильнее IP-Adapter Plus Face (но бенчмарка нет).
4. **ControlNet** — отделяет личность от композиции: задаёшь позу/глубину/контур, личность
   держит LoRA.
5. **Фикс-сид + одинаковый промт + одна модель** = воспроизводимый результат (база для серий).
6. **Character sheet** (турнэраунд) как «pixel-level паспорт личности» для рефа.
7. **Инпейнт по кадрам** — финальный фикс дрейфа (~15% кадров).

## 3. Композиция / поза / камера по кадрам

- **ControlNet** — основной инструмент: OpenPose (поза), depth (объём/композиция), lineart/canny
  (контур/набросок→картинка), scribble (грубый набросок). Скетч-ту-имидж и regional prompting
  для нескольких персонажей/зон в кадре.
- ⚠️ Развенчано: «depth всегда лучше openpose/canny» — НЕ подтвердилось (0-3). Тип ControlNet
  зависит от задачи; не считай depth серебряной пулей.
- Практика: держи **сумму весов ControlNet ~1**, иначе артефакты; canny ~0.4 c окончанием на
  ~0.5 шага — стартовые значения, тюнить.

## 4. Инкинг / колоризация
- AI вписывается через img2img, ControlNet lineart (извлечение контура), AI-recolor/flatting.
- Человек контролит чистоту линий и палитру; финальный рендеринг/тени часто доводят руками.

## 5. Леттеринг — почти всегда вручную
- Диффузия рисует текст в картинке плохо; нужна редактируемость, кернинг, размещение, шрифты.
- Стандарт: **Clip Studio Paint** (есть Story Editor на всю страницу, бабл-инструмент, кернинг,
  текст по кругу, коммерческий шрифт в комплекте — Story Editor только в EX) или **Photoshop**;
  Canva для несерьёзного. Даже ComfyUI-пайплайны **накладывают баблы оверлеем/шрифтом**, а не
  генерируют их (jags111 Speech Bubble overlay, comfyui-panelforge).

## 7. Ранжированные пайплайны под НАШ случай (есть char-LoRA + style-LoRA)

> Единого источника, ранжирующего целые пайплайны, нет — собрано из проверенных компонентов.

**① (рекомендую) ComfyUI-рендер + Krita-доводка + Clip Studio-сборка**
- Рендер кадров: ComfyUI, стек char-LoRA + `cmcstyle`, ControlNet (поза/композиция по кадру),
  фикс-сид, наш улучшайзер (FaceDetailer+апскейл) ВКЛ.
- Доводка по кадрам: Krita AI Diffusion — инпейнт выделением (лицо/руки/дрейф), при нужде
  IP-Adapter/FaceID поверх для подтяжки лица.
- Сборка страницы + баблы + леттеринг: Clip Studio Paint.
- Tradeoff: максимум контроля и качества; средняя скорость; нужно освоить Krita+CSP.

**② Krita AI Diffusion как основной хаб + CSP для леттеринга**
- Всё генеришь и правишь прямо на холсте Krita (рисуешь грубую панель → генерация →
  инпейнт), ComfyUI как бэкенд под капотом. CSP только для вёрстки/баблов.
- Tradeoff: самый плавный итеративный цикл для соло-автора; чуть меньше «программируемого»
  контроля, чем чистый ComfyUI.

**③ Чистый ComfyUI «панель-фабрика» + ручная сборка**
- Граф: multi-LoRA + ControlNet + IP-Adapter + улучшайзер, батч кадров → сборка в CSP/Photoshop.
- Tradeoff: быстро гонит много кадров; правки по кадрам менее удобны, чем инпейнт-на-холсте.

**④ Бюджетный: ComfyUI-рендер + Photoshop/Canva сборка** — если не хочется учить CSP/Krita.

**⑤ (НЕ для нас) Midjourney/zero-training** — плохой контроль личности серийного персонажа.

## 8. Что НЕ верно / развенчано (не трать на это время)

- ❌ «IP-Adapter (scale 0.65) бьёт обученную LoRA по консистентности (84% vs 78% на 600 кадрах)» —
  убито 0-3. Для серий **LoRA надёжнее**.
- ❌ «Нужен ровно ОДИН неизменный мастер-реф в IPAdapter, нельзя менять рефы» — убито 0-3.
- ❌ «depth-ControlNet всегда лучше openpose/canny» — убито 0-3.
- ⚠️ «Triple-Lock = FaceID+LoRA+ControlNet — самый надёжный» — не подтвердилось как «самое
  надёжное» (1-2), но как набор слоёв техники существуют.
- ⚠️ **Числовые пороги** (IP-Adapter 0.65, FaceID 0.7–0.8, Canny 0.4/шаг 0.5) — **анекдотические,
  сильно зависят от базы/контента. Это СТАРТОВЫЕ значения для тюнинга, не оптимум.**

## 9. Вывод для проекта serg0

- Мы в **сильной позиции**: char-LoRA (R1) + `cmcstyle` уже есть → надёжный якорь личности+стиля.
- Стек 2 LoRA (char+style) — в пределах безопасных «2–3», но **проверить эмпирически** (style-bleed
  → при нужде regional prompting / понизить style-strength). Это и закладываем в UI (ползунок
  style-strength уже есть в `gen_improve.py`).
- Для UI создания комикса целимся в **пайплайн ①/②**: ComfyUI-рендер (наш `gen_improve`) +
  ControlNet по кадрам + инпейнт-доводка (Krita-подобный режим или встроенный) + экспорт в
  раскладку/леттеринг. Улучшайзер — обязательным тоглом (уже решено).
- Лицо в проблемных кадрах подтягивать IP-Adapter/FaceID **поверх** LoRA (веса — стартовые из §2,
  тюнить). PuLID/InstantID — кандидаты на будущее, если FaceID не хватит.
- Леттеринг и финальную вёрстку оставляем человеку (Clip Studio Paint) — это by design ручной этап.
